Privacy Policy

vlog-belarusa · effective 14 October 2026

vlog-belarusa is a personal tool of the owner of the YouTube channel «Влог беларуса | Сяргуніка». It is used only by the channel owner, on his own computer, for this one channel.

Data the tool accesses

With the owner's consent given through Google OAuth, the tool uses the YouTube Data API (scope https://www.googleapis.com/auth/youtube.force-ssl) to read and change the owner's own channel: the list of its videos, their titles, descriptions, tags, translations, privacy status and processing status, thumbnails and subtitle tracks.

How the data is used

Only to do what the owner asks for: upload a video, thumbnail or subtitles, update a title or description, compare the files on his computer with what is published, and publish or schedule a video. The data is not used for advertising, profiling, analytics or training of any models.

Storage

The tool has no server. The OAuth token is kept in a local file on the owner's computer. Video identifiers and a short log of changes are kept in local files next to the videos. Nothing is sent anywhere except to Google's own APIs.

Sharing

Data received from Google APIs is not sold, transferred or shared with anyone.

Google API Services User Data Policy

vlog-belarusa's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service; Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time on myaccount.google.com/permissions or security.google.com/settings/security/permissions. Deleting the local token file removes the stored credentials.
